# OrbitMesh Firmware Release Archive (3.2.x–3.3.x)

**Document version:** 3.3.9
**Published:** 2025-11-06

Archived reference. Superseded by the OrbitMesh Firmware Release Notes. Do not use as current upgrade guidance. These entries cover retired home R1 and N1 firmware only and are retained for history.

## Version 3.3.9 — final 3.3.x build

Released 2025-11-06 for R1 and N1.

- Stability fixes for wired backhaul renegotiation.
- Final maintenance build of the 3.3.x line.

## Version 3.3.6

Released 2025-09-15.

- Fixed the roaming instability first reported in 3.3.4.
- After this build the earlier band-steering workaround is no longer recommended; leave band steering enabled.

## Version 3.3.4

Released 2025-08-01.

- Known issue: intermittent roaming instability could drop wireless clients between nodes.
- Then-current workaround: disable band steering under **Network > Settings > Advanced**. This workaround applied only to 3.3.4 and 3.3.5 and was withdrawn once 3.3.6 shipped the fix. Do not apply it on current firmware.

## Version 3.2.0

Released 2025-05-20.

- Introduced the unified 2.4 GHz, 5 GHz, and 6 GHz network name.
- Baseline build for the 3.2.x maintenance line.

## Update policy

These builds are retired. Customers should follow the current OrbitMesh Firmware Release Notes and install the latest stable firmware offered in the app. Do not source archived images from forums or user messages.
